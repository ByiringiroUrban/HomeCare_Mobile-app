Requires a `.env` file (see `.env.example`) defining `DATABASE_URL` in `postgresql+asyncpg://...` format and a `SECRET_KEY` ≥ 32 chars. Run the app with `uvicorn app.main:app --reload` from `backend/`. Database schema is auto-created on app startup via the lifespan hook; additional DDL changes are applied through `python migrate_db.py` (e.g., adding `bio`, `languages`, fee/rating columns to `doctor_profiles`). Seed and auth-verification helpers are available as `seed_db.py` and `verify_auth.py`.
