The root is a standard Expo project: `index.ts` registers `App.tsx` as the root component, which is the entry point consumed by both Expo Go and native builds. Routing is file-based under `src/app/` via the `expo-router` plugin declared in `app.json`, while global app state uses Zustand and data fetching uses TanStack Query. The TypeScript config extends `expo/tsconfig.base` with strict mode and an `@/*` path alias pointing at `src/`. The only backend dependency is the sibling `backend_api` FastAPI service; this mobile module consumes it over HTTP (no shared code).
